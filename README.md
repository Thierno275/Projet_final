# Smart Fuel - Estimation et Optimisation du Prix des Carburants

## Objectif
- Analyser : Étudier les prix des carburants en France et comprendre leurs dynamiques de variation
- Prédire : Construire un modèle de prédiction des prix basé sur le Machine Learning
- Recommander : Développer un système de recommandation des stations les plus avantageuses
- Déployer : Créer une application interactive avec Streamlit, orientée utilisateur

## Technologies
- Python (Pandas, Matplotlib, Seaborn)
- Streamlit (Développement web)

## Contenu
- Smart_Fuel_Barry_Thierno.ipynb : Notebook
- Projet-Smart-Fuel_gamma.pdf : Présentation
- Smart_Fuel.py : Application Web

- Ouvrir le notebook avec Jupyter / Colab
- Ouvrir le .py avec une page web
